# MalikLyons

## 📚 My Library — free, private audiobook app

The [`my-library/`](my-library/) folder contains **My Library**, a personal audiobook web app: import PDF, EPUB, DOCX or TXT
books and listen to them with your device's free voices. Works offline and installs on iPhone from Safari.

See [my-library/README.md](my-library/README.md) for features, how to run it, and how to install it on your iPhone.
